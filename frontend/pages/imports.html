CSV Format Information

Your CSV file should include the following columns:

Column Name Description Required Example
Employee_ID Unique identifier for the employee Optional 101
Name Full name of the employee Required John Smith
Designation Job title or position Required Senior Developer
BPS Grade of the employee Optional BS-17
Office_Hierarchy Department or organizational structure Optional Technology>Development
From Start date of report period (YYYY-MM-DD) Required 2023-10-01
To End date of report period (YYYY-MM-DD) Required 2023-10-08
Tasks_Completed Description of completed tasks Required* Implemented new feature
Impact Impact of the completed tasks Optional Improved system performance
Challenges Challenges faced during the period Optional Integration issues
Support_Required Support or resources needed Optional Additional testing resources
Tasks_Planned Tasks planned for next period Optional Finalize documentation
Confidence_Level Confidence level (1-5) Optional 4
NTR Nothing to report reason Optional** On leave

* Either Tasks_Completed must be provided or NTR must be specified.
** If NTR is provided, a report will not be created.
